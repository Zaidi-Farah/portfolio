## Run locally

No build tool is required.

Open `index.html` directly in a browser, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages

Push the repository to GitHub and enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

## Before publishing

Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your real profile URLs.

If you later add project repositories, update the project links in the portfolio.
